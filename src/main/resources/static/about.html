About This Project

A DevOps L1 practice lab disguised as a VALORANT fan site.

What is this?

VALORANT Tactical Hub is a small, deliberately simple Java web application. Its real purpose isn't the website itself — it's everything around the website: version control with Git, building with Maven, packaging into a runnable JAR, containerizing with Docker, serving through Nginx, running as a Linux service with systemd, and automating the whole pipeline with Jenkins on an AWS EC2 Ubuntu instance.

Every DevOps concept below has a genuine reason to exist in this project — nothing here is included "just for show". See the project README in the repository for full setup instructions, practice labs, a troubleshooting workbook, and an interview-question bank.

Agent, map and weapon artwork is intentionally not reproduced here. Instead, each entity is rendered with a generated color badge, so the project stays focused on data and DevOps rather than licensed game assets. This site is a non-commercial, fan-made practice project and is not affiliated with or endorsed by Riot Games.
